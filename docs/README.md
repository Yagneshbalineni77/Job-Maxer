# docs/

Put your own files here. Nothing in this folder is committed (see `.gitignore`).

The file names must match the `docs` section of your `profile.json`. The defaults are:

| File | Used for |
|---|---|
| `resume.pdf` | Every application (required) |
| `cover_letter.pdf` | Forms that ask for a cover letter (optional) |
| `photo.jpg`, `signature.jpg` | Government portals only. Never attached on company sites |
| `class10.pdf`, `class12.pdf`, `degree.pdf`, ... | Government portals only |
| `aadhaar.pdf`, `pan.pdf` | Government portals only. Never sent to company sites |

Leave an entry empty (`""`) in `profile.json` if you don't have that file.
